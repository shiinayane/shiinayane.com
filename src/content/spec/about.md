# About

I'm a graduate student in Tokyo, working on robots in scientific laboratories. Outside the lab, I mostly write Swift or fix things that bother me in software I use every day.

These are the projects I still actively work on.

## Main Projects

### BiliKit for Mac

A native, unofficial Bilibili client for macOS. The first release shipped in September 2026, and signed, notarized builds are available from GitHub Releases. It covers recommendations, trending, search, QR sign-in with watch-history sync, Watch Later, and favorites; playback supports subtitles, danmaku, and multi-part videos. It requires an Apple Silicon Mac running macOS 15 or later.

::github{repo="shiinayane/BiliKit-Mac"}

### KotobaLab

An iOS Japanese dictionary and study app for N1+ learners. The dictionary is stored locally for offline search, while saved words and other personal data are kept separately. It is still in development.

::github{repo="shiinayane/KotobaLab"}

### LabMate

My research project. It looks at how a robot should respond to natural-language instructions: when to ask for clarification, whether an action is safe, and how to recover from failure. The current work focuses on reproducible simulation experiments in LabUtopia and Isaac Sim.

::github{repo="shiinayane/LabMate"}

## Other Projects

### BiliKit-Web

A set of Bilibili userscripts built to work well in Safari on macOS, including everyday enhancements and an app-style recommendation feed. It started as something for my own use and later split into independently installable Core and Feed scripts, which are now available on GreasyFork.

::github{repo="shiinayane/BiliKit-Web"}

### BewlyCat Safari

A Safari maintenance branch of BewlyCat. I use it to keep up with upstream changes and fix compatibility issues on Safari for macOS.

::github{repo="shiinayane/BewlyCat-Safari"}
