# 关于

现在在东京读研究生，研究方向和实验室里的机器人有关。课外时间基本都在写 Swift，或者修一些自己每天会遇到的问题。

下面是目前还在持续做的项目。

## 主要项目

### BiliKit for Mac

原生、非官方的 macOS B 站客户端。现在已经可以浏览和搜索视频，也做了登录、观看历史、字幕、弹幕和播放。还在继续补日常使用需要的功能，暂时没有发布。

::github{repo="shiinayane/BiliKit-Mac"}

### KotobaLab

面向 N1+ 学习者的 iOS 日语词典与学习应用。词典保存在本地，可以离线搜索；收藏等个人数据单独保存。目前仍在开发中。

::github{repo="shiinayane/KotobaLab"}

### LabMate

研究项目。它关注机器人收到自然语言指令后，如何判断要不要追问、动作是否安全，以及失败后怎么恢复。目前主要在 LabUtopia／Isaac Sim 中做可复现的仿真评测。

::github{repo="shiinayane/LabMate"}

## 其他项目

### BiliKit

一组 B 站 userscript，包括常用功能增强和一个 App 风格的推荐流。最初只是自己用，后来慢慢拆成了可以独立安装的 Core 和 Feed。

::github{repo="shiinayane/BiliKit"}

### BewlyCat Safari

BewlyCat 的 Safari 维护分支，主要处理 macOS Safari 的兼容问题，并跟进上游更新。

::github{repo="shiinayane/BewlyCat-Safari"}
